# 📦 Estación de Envíos y Paquetes 'EnvíaYa'

Este es un software de escritorio desarrollado para la agencia postal 'EnvíaYa'. Su propósito es gestionar la recepción, pesaje, clasificación e inspección de envíos en la bahía de carga. 

El proyecto destaca por integrar una interfaz gráfica de usuario fluida con un núcleo de procesamiento de datos construido **exclusivamente mediante funciones recursivas**, cumpliendo con los requerimientos técnicos de evaluación.
